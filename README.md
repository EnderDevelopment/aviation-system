# Aviation System

Comprehensive aviation system for FiveM with licenses, jobs, vehicles, and emergencies.

## Features

- Licenses management
- Jobs management
- Vehicles management
- Emergencies management

## Requirements

- FiveM server
- ESX Legacy framework
- MySQL database

## Installation

1. Download the script and place it in your `resources` folder.
2. Import the `database.sql` file into your MySQL database.
3. Add `start AviationSystem` to your `server.cfg` file.

## Usage

- Press F5 to open the aviation menu.
- Navigate through the menu to manage licenses, jobs, vehicles, and emergencies.

## Configuration

The script can be configured in the `config.lua` file. You can add or remove licenses, jobs, and vehicles as needed.
